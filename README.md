# Serum's Umbrel apps

An Umbrel community app store.

In umbrelOS go to **App Store → ⋯ → Community App Stores**, paste this repo's URL, and add it.

| App | Description |
| --- | --- |
| Sokjan | Fast, lightweight BitTorrent DHT crawler with a web manager and a Torznab API for Sonarr/Radarr |

After installing, add Sokjan to Prowlarr/Sonarr/Radarr as a Generic Torznab indexer:
URL `http://umbrel.local:7650/torznab`, API path `/api`.
